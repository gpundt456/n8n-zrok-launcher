# n8n-zrok-launcher

A Python script that launches n8n locally, exposes its webhooks through a public HTTPS tunnel using zrok, and automatically configures Telegram webhooks through the Telegram Bot API.

## Why I Built This

I use n8n to automate different AI workflows on my own computer. One problem I ran into was getting external services like Telegram to communicate with my local n8n instance without needing cloud hosting.

I used zrok to create a public HTTPS tunnel, but the URL could change whenever I restarted it. This meant I had to repeatedly update webhook configurations and restart services manually.

I created this project to automate that process. Instead of manually starting services, finding the new tunnel URL, and updating Telegram, I can launch the system through a Windows batch file.

## Features

- **Automated n8n startup:** Launches a locally hosted n8n instance.
- **Public HTTPS tunneling:** Uses zrok to make local webhook endpoints accessible from the internet.
- **Automatic URL detection:** Captures the public HTTPS URL generated by zrok.
- **Webhook configuration:** Restarts n8n with the updated public webhook URL.
- **Telegram integration:** Optionally registers a Telegram webhook through the Telegram Bot API.
- **Windows batch launcher:** Allows the Python program to be started through a `.bat` file rather than manually entering commands.
- **Webhook filtering:** The public version uses a proxy that restricts external access to production webhook endpoints.
- **Port conflict detection:** Checks whether required local ports are occupied.
- **Process management:** Monitors n8n and zrok and shuts down the processes it started when the launcher stops.
- **Environment-based configuration:** Stores local configuration and sensitive credentials outside the Python source code.

## How It Works

1. The Windows batch file starts the Python launcher.
2. The Python script starts a local webhook-filtering proxy and launches n8n.
3. It starts a zrok tunnel, which generates a public HTTPS address.
4. The script detects that address and restarts n8n with the updated webhook configuration.
5. If Telegram credentials are configured, it registers the public webhook URL with Telegram.
6. The script monitors the running services and handles cleanup when stopped.

The n8n editor remains accessible on the local computer, while the public tunnel forwards requests through the filtering proxy.

## Installation

**1. Download the repository**

Download or clone the repository onto your computer.

**2. Install the required Python packages**

Open a terminal in the project folder and run:

```bash
pip install -r requirements.txt
```

**3. Configure environment variables**

Make a copy of `.env.example` and rename it to `.env`.

Configure your n8n and zrok executable paths if they aren't available through your system PATH. Optionally, add your Telegram bot token and webhook identifier.

**4. Start the launcher**

On Windows, double-click:

```text
launch_n8n.bat
```

Alternatively, run the Python program directly:

```bash
python start_n8n.py
```

You can create a desktop shortcut to `launch_n8n.bat` for easier access.

**5. Access n8n**

By default, the local editor is accessible at:

```text
http://127.0.0.1:5678
```

The launcher will also display the generated public zrok URL.

## Security

The public GitHub version has been modified to remove my personal configuration and credentials.

It uses a webhook-filtering proxy rather than exposing the entire n8n application through the public tunnel.

Credentials are stored in a local `.env` file, which should never be committed to GitHub.

The proxy restricts accessible routes but does not replace webhook authentication. Individual workflows should use appropriate security controls.

Some n8n features that require additional public routes, such as certain interactive forms or callbacks, may need further proxy configuration.
